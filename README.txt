LABORATORIUM WIEDZY — STARTER QUARTO

CO JEST W PACZCE
- komplet plików strony Quarto
- menu i podstrony
- arkusz stylów styles.css
- folder assets/ na zdjęcia

INSTRUKCJA
1. Rozpakuj archiwum.
2. Wstaw własne zdjęcia JPG do folderu assets/.
3. Zachowaj nazwy z pliku assets/README-ZDJECIA.txt.
4. Otwórz kontakt.qmd i podmień e-mail, telefon oraz linki.
5. Otwórz terminal w folderze projektu i uruchom:
   quarto render
6. Powstanie folder docs/.
7. Dodaj CAŁY projekt oraz folder docs/ do repozytorium GitHub.
8. GitHub: Settings > Pages > Deploy from a branch > main > /docs > Save.

EDYCJA
Pliki .qmd możesz edytować w RStudio lub Visual Studio Code z Quarto.
